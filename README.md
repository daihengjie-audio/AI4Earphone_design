# AI4Earphone Design

耳机、AI 眼镜与开放式音频设计项目的研究、专利分析、技术交底和独立 QA 文档归档。

## 目录

- `documents/current/`：当前交付文档，包括中日双语专利评估、通俗说明、AI 加速设计调研、工程证据和独立 QA。
- `documents/history/`：阶段性研究、现有技术检索、论文证据、冻结报告、技术交底书及其 QA 记录。

## 使用边界

- 专利检索和公开文本分析不等同于正式法律意见、侵权判断或 FTO 结论。
- 专利号、申请人、法律状态和链接应在正式申请或决策前按目标法域刷新。
- 研究结论和厂商宣称不得未经样机与独立测试直接外推为产品性能。
- `history` 中保留部分中间版本，正式使用时应优先选择文件名含 `frozen`、`qa_r1`、最终时间戳或位于 `current` 的版本。

## Archive structure (English)

- `documents/current/`: current deliverables and bilingual review documents.
- `documents/history/`: prior-art research, evidence dossiers, frozen reports, technical disclosures, and QA records.

Public-source patent analysis in this repository is not legal advice or a completed freedom-to-operate assessment.
