# Qosmo クローズドループ睡眠支援システム：3フェーズ共同開発計画および検収基準 v0.2

**用途：** 共同開発契約書／SOW（作業範囲記述書）の作成および各フェーズの検収  
**共同開発範囲：** Qosmoは、睡眠状態および生理学的特徴量に基づく睡眠支援オーディオ戦略、リアルタイム生成／編曲、再生制御ならびに効果検証を担当する。脳波取得、睡眠段階判定および徐波位相検出については、発注者または他の協力機関が提供する。

---

## フェーズ1：全体構想の策定

【フェーズ1期間】  
2か月

【業務内容】

1. 睡眠の質の改善を目的として、産業界および学術界における音響による睡眠支援ならびにオーディオ・クローズドループ制御技術を調査、分析し、体系的に整理する。特に、音の種類および音楽的特徴が、入眠、睡眠段階、脳波、心拍数／心拍変動等の指標に及ぼす影響を検討し、技術原理、適用場面、有効性のエビデンスおよび限界を整理する。
2. リアルタイム・クローズドループ睡眠支援を対象として、「睡眠状態／生理学的特徴量の入力―制御戦略―音楽パラメータ―音響出力―効果フィードバック」から成る全体技術構想を策定する。本構想では、入力信号、状態から音楽へのマッピング規則、開始／維持／切替／停止ロジック、異常時のフォールバックおよび効果評価方法を明確にする。
3. リアルタイム自由生成、制約付き生成、楽曲ライブラリ検索およびリアルタイム編曲等の技術方式を比較・選定し、主方式、代替方式、実装形態、ソフトウェア／ハードウェア構成ならびに要求仕様を明確にする。
4. 技術的実現可能性の検証計画を策定し、フェーズ2で構築するプロトタイプのシステム構成、インターフェース、性能指標、試験方法およびフェーズ3のヒト対象効果検証計画を明確にする。

【成果物】

1. 『音響による睡眠支援およびオーディオ・クローズドループ制御技術分析報告書』1部。
2. 『Qosmoクローズドループ睡眠支援システム全体技術構想書』1部。
3. 『プロトタイプシステム選定・パラメータ仕様・検証計画書』1部。

【検収基準】

1. 『音響による睡眠支援およびオーディオ・クローズドループ制御技術分析報告書』に、以下を含むこと。
   1）主要な音響睡眠支援技術の技術方式、制御原理および適用可能な睡眠場面。  
   2）有効性のエビデンス。実験計画、対照条件、被験者の属性と人数、睡眠および生理学的指標、主要結果ならびにエビデンスの限界を含むこと。  
   3）音の種類および主要な音楽的特徴が、脳波、心拍数／心拍変動、入眠ならびに睡眠構造に及ぼす可能性のある影響。  
   4）各技術方式の長所、短所、リスクおよび製品化成熟度。  
   5）制御効果の評価指標および評価方法。
2. 『Qosmoクローズドループ睡眠支援システム全体技術構想書』に、以下を含むこと。
   1）システム目標、対象者、利用場面および共同開発の責任範囲。  
   2）エンドツーエンドのシステム構成、各モジュールの機能、データフローおよび制御フロー。  
   3）睡眠状態／生理学的特徴量の入力要件。データ項目、タイムスタンプ、更新頻度、信号品質および信頼度の要件を含むこと。  
   4）状態から音楽パラメータへのマッピング原則、ならびに開始、維持、切替、フェードアウト、停止および安全時フォールバックのロジック。  
   5）音楽の生成／検索／編曲方式、ならびに音量、テンポ、音色、複雑性、連続性等のパラメータ制御原則。  
   6）ログ、バージョン管理、オフライン再現、異常処理およびユーザーによる能動停止機能。
3. 『プロトタイプシステム選定・パラメータ仕様・検証計画書』に、以下を含むこと。
   1）リアルタイム自由生成、制約付き生成、楽曲ライブラリ検索およびリアルタイム編曲等の方式について、比較根拠および選定結果。  
   2）主方式および直ちに適用可能な代替方式。  
   3）プロトタイプのソフトウェア／ハードウェア選定、主要モジュール、インターフェース、実装形態および第三者依存関係。  
   4）状態更新周期、戦略演算遅延、音響応答遅延、連続稼働、音響出力および安全限界等の要求仕様。  
   5）フェーズ2の試験項目、評価指標および合格基準値。  
   6）フェーズ3の対象者、対照条件、主要／副次評価項目、サンプルサイズおよび統計解析の原則。  
   7）ソースコード、モデル、音楽コンテンツ、出力音源、研究データおよび新規知的財産権の帰属ならびに利用範囲。
4. 3つの報告書間で内容が整合しており、要求事項、モジュール、パラメータおよび検収指標を項目単位で追跡できること。主方式、代替方式、定量仕様または知的財産権の範囲が明確でない場合、フェーズ1の検収は不合格とする。

## フェーズ2：プロトタイプシステムの構築

【フェーズ2期間】  
3か月

【業務内容】

1. フェーズ1で確定した全体構想に基づき、睡眠状態／生理学的特徴量の入力、戦略判定、音楽生成または編曲、音響再生制御、ログ記録およびオフライン再現までを一体化したクローズドループ睡眠支援プロトタイプを構築する。
2. 状態から音楽パラメータへのリアルタイム・マッピング、ならびに開始、維持、切替、フェードイン／フェードアウト、停止および安全時フォールバック機能を実装する。信号品質不足、状態不明、入力中断またはシステム異常時には、新たな刺激を追加せず、安全状態へ移行する。
3. 模擬データおよび記録済み生理データを用い、インターフェース、機能、遅延、安定性、異常注入、音楽の連続性およびパラメータ適合性を試験する。
4. プロトタイプの導入、使用、試験および引渡しに必要な資料を整備し、フェーズ3のヒト対象効果検証に用いるバージョンを確定する。

【成果物】

1. Qosmoクローズドループ睡眠支援プロトタイプシステム1式。
2. 『プロトタイプシステム技術設計書およびインターフェース仕様書』1部。
3. 『プロトタイプシステム技術試験報告書』1部。
4. プロトタイプシステム引渡しパッケージ1式。合意した範囲のソフトウェア、モデル／戦略設定、音楽コンテンツパッケージ、導入用ファイル、試験ツールおよび取扱説明書を含むこと。

【検収基準】

1. Qosmoクローズドループ睡眠支援プロトタイプシステムに、以下の機能を実装すること。
   1）フェーズ1で合意した睡眠状態、生理学的特徴量、信号品質、信頼度およびタイムスタンプを受信できること。  
   2）入力状態に基づき、音楽戦略および音楽パラメータをリアルタイムに選択または調整できること。  
   3）生成／検索／編曲、再生、フェードイン／フェードアウト、停止および安全時フォールバックを実行できること。  
   4）入力、戦略判定、実際の音楽パラメータ、再生イベント、異常ならびにソフトウェア／モデル／コンテンツのバージョンを完全に記録できること。  
   5）統一された時間軸上でオフライン再現を行い、各クローズドループ判定を再現できること。  
   6）ユーザーによる能動停止および発注者が定める安全制限に対応すること。
2. 『プロトタイプシステム技術設計書およびインターフェース仕様書』に、システム構成、各モジュールの機能、インターフェース項目、状態遷移、音楽パラメータ、時系列要件、エラーコード、実行環境、依存関係一覧およびバージョン管理方法を含むこと。
3. 『プロトタイプシステム技術試験報告書』に、以下を含むこと。
   1）フェーズ1で定めた全試験項目の結果、原記録、不具合および是正状況。  
   2）エンドツーエンド遅延、戦略／パラメータ適合率、連続稼働時間、異常時フォールバック成功率およびログ完全性等の指標。  
   3）音楽の連続性、自然さ、入眠への適合性および異常音についての客観・主観評価。  
   4）入力消失、遅延、順序入替、低信号品質、状態不明、ネットワーク／サービス中断および再生中断等の異常試験結果。
4. プロトタイプの性能は、フェーズ1で確定した基準値を満たすこと。最低基準として、以下を推奨する。
   1）必須機能実装率100％。  
   2）安全時フォールバック成功率100％、かつ安全に関わる誤刺激0件。  
   3）入力、判定、出力およびバージョンに関するログ完全性100％。  
   4）戦略演算遅延P95が500 ms以下、かつ聴覚上認識可能な音楽変化が1小節以内に生じること。  
   5）8時間以上の連続稼働中に、クラッシュ、状態遷移のデッドロックまたは再現不能イベントが発生しないこと。  
   6）検収を妨げる重大不具合が0件であること。
5. 発注者が、合意した環境において引渡しパッケージを用いて独立して導入、実行および試験結果の再現を行えること。Qosmoによる現地デモのみ可能で、独立導入または再現ができない場合、フェーズ2の検収は不合格とする。

## フェーズ3：効果検証

【フェーズ3期間】  
4か月。倫理審査および被験者募集に要する期間は別途協議の上で確定する。

【業務内容】

1. ヒト対象試験に先立ち、シャドー運用を行う。システムは実際の睡眠／生理入力を読み取り、判定を生成するが、適応的な音響変化は実際には再生しない。これにより、判定の正確性、遅延、誤作動、信号品質ゲーティングおよび安全時フォールバックを検証する。
2. 無作為化対照ヒト試験を実施し、クローズドループ睡眠支援システムの安全性、ユーザビリティおよびオープンループ音響に対する上乗せ効果を検証する。少なくとも、固定された最適音響、個別化オープンループ音響およびリアルタイム生理連動型クローズドループ音響を設定することを推奨する。条件が許す場合は、無音またはシャム刺激の対照条件を追加する。
3. 入眠、睡眠構造、脳波および自律神経系の生理学的変化、主観的睡眠の質、音響受容性、妨害／覚醒、機器の取り外し／停止ならびに継続使用意向を評価する。
4. クローズドループシステムが適用可能な対象者、睡眠段階、有効戦略、無効または高リスクとなる場面を分析し、製品化、適用範囲の限定、オープンループ方式への移行または開発中止に関する提案を行う。

【成果物】

1. 『クローズドループ睡眠支援ヒト対象効果検証計画書』1部。
2. 『シャドー運用およびシステム正確性検証報告書』1部。
3. 『クローズドループ睡眠支援効果検証報告書』1部。
4. ヒト対象研究データおよびイベントログ一式。
5. 『製品化提案および最終技術引渡し報告書』1部。

【検収基準】

1. 『クローズドループ睡眠支援ヒト対象効果検証計画書』に、以下を含むこと。
   1）研究目的、対象者、選択／除外基準、サンプルサイズの根拠および中止基準。  
   2）無作為化、対照、盲検化、試験期間および条件実施順序。  
   3）単一の主要評価項目、副次評価項目、作用機序指標、安全性指標および製品上意味のある最小差。  
   4）データ収集、品質管理、欠測データ、多重比較および統計解析の方法。  
   5）確定したソフトウェア、モデル、戦略、音楽コンテンツ、機器および設定のバージョン。
2. 『シャドー運用およびシステム正確性検証報告書』により、以下を確認できること。
   1）有効な信号品質、許容された状態および安全時間帯に限り、システムがクローズドループ判定を生成すること。  
   2）判定、実際の再生、停止および異常を、統一された時間軸上で再現できること。  
   3）誤作動、遅延、状態変動、入力中断およびフォールバックが完全に記録されていること。  
   4）安全に関わる誤刺激が0件であり、ヒトへの音響提示検証の開始条件を満たすこと。
3. 『クローズドループ睡眠支援効果検証報告書』に、以下を含むこと。
   1）各対照条件における入眠、睡眠構造、脳波／自律神経系生理、主観評価、安全性およびユーザビリティの結果。  
   2）クローズドループ音響と個別化オープンループ音響との差、効果量、信頼区間、個人差および夜間変動。  
   3）脱落、欠測、順序効果、持越し効果および感度分析。  
   4）反応者、非反応者、妨害を受けやすい対象者および適用戦略の分析。  
   5）事前に定めた全評価項目の結果。肯定的な結果のみを選択して報告してはならない。
4. ヒト対象研究データおよびイベントログ一式には、匿名化データ、データ辞書、品質管理記録、ならびに夜単位で対応付け可能な入力状態、クローズドループ判定、実際の再生およびバージョン情報を含み、データ完全性が研究計画で定めた基準を満たすこと。
5. フェーズ3の契約上の検収は、「確定した計画に従って研究が適正に完了し、データが完全で、分析が再検証可能であり、報告が正確かつ完全であること」を基準とし、肯定的な有効性結果が得られること自体を必須条件としない。有効性の結果は、以下の製品判断に用いる。
   1）クローズドループ方式が個別化オープンループ方式に対して、事前に定めた製品上意味のある最小差を満たし、かつ許容できない安全性または妨害リスクがない場合：製品化を推奨する。  
   2）音響または個別化の効果は認められるが、クローズドループによる上乗せ効果がない場合：固定式／個別化オープンループ方式へ移行する。  
   3）特定対象者に限り有効な場合：対象者および戦略を限定した上で再検証する。  
   4）睡眠上の価値が認められない、または安全性・妨害リスクが許容できない場合：当該技術方式を中止する。

## 契約書に明記すべき共通事項

1. 各フェーズの検収対象について、ソフトウェア、モデル、戦略、音楽コンテンツ、機器および設定のバージョンを確定すること。
2. 各フェーズの支払条件を、成果物の完全性、定量検収結果、重大不具合の解消および知的財産権の明確性に連動させること。
3. 既存知的財産、新規知的財産、ソースコード、モデル、音楽コンテンツ、出力音源、研究データならびに論文発表／広報に関する権利を明確にすること。
4. Qosmoは、第三者モデル、学習／参照コンテンツ、クラウドサービスおよびライセンス制限を開示し、再許諾できないコンテンツまたは個人アカウントに依存して成果物を提供してはならない。
5. 検収不合格の場合は、合意に基づき、是正、範囲縮小、代替方式への切替または終了を実施し、自動的に次フェーズへ移行しないこと。
