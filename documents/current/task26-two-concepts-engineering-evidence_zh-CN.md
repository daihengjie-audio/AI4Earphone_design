# 两项新构想工程证据 dossier（task #26）

版本：2026-08-13 v1.0  
范围：仅评估工程可实施性、论文/标准证据和样机验证基线；不构成专利查新、可授权性、FTO、医疗器械或人体安全结论。

## 0. 结论先行

### 构想 1：有限行程内低力波动的 CC 接触机构

工程上可行，但应把“恒力”改写为可验收的 **“在规定头宽/位移、温度、循环次数和加载方向内，接触力波动受限”**。最值得优先验证的两条路线为：

1. **镜腿侧凸轮—弹簧/恒扭矩补偿**：行程较大、目标力可调、过载止挡容易设置；代价是摩擦、间隙、磨损和体积。
2. **CC 浮动座＋柔顺/屈曲负刚度补偿**：紧凑、无传统铰链摩擦，可把镜腿宏观弯曲与局部法向接触解耦；代价是横向失稳、制造公差、材料蠕变/疲劳和装配预载敏感。

泡棉、硅凝胶、超弹性 NiTi 更适合作为 **顺应、阻尼、回中或调节元件**，不宜单独承担长期“恒力”主功能；其迟滞、应力松弛、温漂和循环漂移必须进入权利要求实施例及验证门槛。

### 构想 2：Air Mic＋VPU 接触/失真感知

工程上可行，但 VPU 不是“只接收纯固体振动”的理想传感器，也不能天然“完全分离”CC、气导扬声器和镜架辐射。可保护且可实施的核心应改为：

- 使用 **已知的 CC/气导驱动参考信号＋Air Mic＋一枚或两枚 VPU**，在线估计多路径传递函数、接触状态和非线性残差；
- 用自适应线性模型跟踪缓慢变化的线性路径，用 NN/分类器估计接触等级、松动/跳动与非线性状态，并对更新设置置信门控和稳定性限制；
- 将 VPU 作为“增强可观测性”的辅助传感器，而不是把它描述为绝对隔绝空气声的干净参考。

一枚 VPU 同时用于通话和状态感知具有条件可行性，但播放期间会受致动器自干扰、动态范围和饱和限制。应采用已知播放参考消除、分帧/分频共享、状态门控或双增益链，并把“全双工同时工作”列为独立样机门槛。

## 1. 证据分级

- **D：直接证据**——来源直接测量了所述机制/信号路径或给出官方器件/标准条件。
- **I：工程推断**——由直接证据合理迁移到眼镜 CC 场景，但尚未在目标样机证实。
- **V：待验证**——目前没有足够公开证据支持具体数值或绝对效果，必须通过样机实验确定。

### 2.2 建议的机构定义与参数化

不要把目标写成单一的“恒力”。建议使用下列可测参数：

- 规定工作位移区间：`x ∈ [x_min, x_max]`，由目标人群头宽和耳位统计转换，不预先臆造毫米值。
- 目标接触力：`F_target`，由假耳声学＋舒适/皮肤安全验证共同确定。
- 平台误差：`e_F = max|F(x)-F_target|/F_target`。
- 滞回：同位移加载/卸载力差的最大值及滞回环面积。
- 松弛：恒定位移 30 min、2 h、8 h 后的力保持率。
- 横向稳定：侧向位移、扭转角和屈曲分支跳变。
- 耐久漂移：循环后 `F_target`、`e_F`、零位和噪声/异响变化。
- 过载安全：机械止挡行程、最大耳部力、失效后是否保持低风险状态。

### 2.3 两条优先原型路线

#### A. 镜腿侧凸轮—弹簧补偿

结构：弹簧或柔性梁产生随开合角增加的回复力；变半径凸轮/连杆使有效力臂随角度减小，以获得指定输出力曲线。建议增加滚子、双向限位、预载调节和防脱结构。

- 直接证据：M1、M2 证明凸轮—弹簧有限行程力整形可行。
- 工程推断：将输出端从直线压头换成镜腿—CC 法向力，需同时建模开合角、镜腿柔度、耳部法向和切向分量。
- 待验证：镜腿尺寸内能否维持目标平台、摩擦/间隙是否引起可感知力跳变、汗液/灰尘/磨耗后的漂移。

#### B. 浮动 CC 座＋正/负刚度补偿

结构：CC 模组沿耳部法向有受限浮动行程；平行四边形柔顺导向或弹片保持姿态；屈曲梁/预屈曲片提供负刚度，线性弹性元件提供正刚度；软垫只做界面顺应与阻尼；机械止挡限制过载。

- 直接证据：M3–M5 证明正负刚度匹配可产生有限行程力平台；M6 证明浮动/悬臂安装有利于接触力可重复。
- 工程推断：该结构可降低镜腿宏观弯曲对局部 CC 法向力的影响。
- 待验证：屈曲分支是否发生横向跳变、装配公差/预载是否显著缩短平台、耳部曲面是否产生切向滑动。

### 2.4 材料路线边界

- **NiTi 超弹性件**：优点是高可恢复应变和可形成平台；风险是温度、应变率、热处理和循环造成平台/迟滞变化。必须对上/下平台强度、残余伸长、温度漂移和循环漂移做来料与整机双层验证。
- **低模量硅凝胶**：适合贴合与阻尼，但黏弹性导致应力松弛；不应把初始压缩曲线等同于 8 h 佩戴力。
- **微孔泡棉**：适合扩大接触面积和吸收公差；孔径、密度、压缩永久变形和湿热老化决定长期力，不宜作为唯一恒力元件。
- **常规弹簧钢/聚合物柔顺梁**：制造成熟，但需校核应力集中、疲劳、温度和注塑/冲压公差。

### 3.2 可辨识性：为什么不能只写“VPU 分离信号”

令已知驱动参考为 `u_cc(t)` 和 `u_ac(t)`，Air Mic 与 VPU 观测可简化为：

`y_air = H_cc→air(q)u_cc + H_ac→air(q)u_ac + n_air + r_nl`

`y_vpu = G_cc→vpu(q)u_cc + G_ac→vpu(q)u_ac + v_frame + v_voice + n_vpu`

其中传递函数随接触力、位置、头型和温度变化，`r_nl` 包含接触跳动、饱和及软组织非线性残差。

关键结论：

1. 如果系统已知两个扬声器的驱动参考，便可进行多输入系统辨识；VPU 增加接触/结构路径的可观测性。
2. 如果只有 Air Mic＋一枚 VPU，而播放源、用户语音和外部噪声均未知且同时存在，问题可能欠定，不能保证唯一分离。
3. 双 VPU 只有在两枚传感器对“耳部局部路径”和“镜架路径”的传递向量足够不同、频率点上的混合矩阵条件数可接受时，才有增益；位置不同不自动等于可分离。
4. 接触跳动是时变/非线性事件。线性自适应滤波适合跟踪稳定段，NN/分类器适合输出接触状态或非线性置信度；发生跳动时应冻结或降速更新，防止错误发散。

以下为样机起始值（I/V），不是最终产品规格：

| 位置 | 主要目标 | 安装建议 | 初始采样/分析范围 | 主要风险 |
|---|---|---|---|---|
| VPU-A：CC 致动器背面或浮动座刚性岛 | 估计致动器—耳部耦合、负载变化、跳动；兼顾本人语音 | 主敏感轴尽量沿耳部法向；与致动器壳体刚性耦合，但与镜腿主体受控隔离；保留已知驱动参考 | 原始采样≥16 kHz；扫频 50 Hz–8 kHz；接触特征先从 100 Hz–3 kHz 数据驱动选择 | 播放自干扰/饱和；本人说话与播放叠加；软垫改变传递函数 |

“100 Hz–3 kHz 接触特征带”仅是基于 CC 低频路径与 VPU 语音带宽证据的起始搜索区。最终应通过训练集上的互信息、相干度、接触力回归误差和跨人泛化确定，不应写成固定物理边界。

### 3.4 同一 VPU 兼顾通话与状态感知

建议架构：

- 前端保留足够动态范围，至少记录播放参考、VPU 和 Air Mic 的同步时钟数据；
- 先用已知播放参考做自干扰建模/回声抵消，再分出本人语音特征与接触特征；
- 通话输出走 AC＋VPU 融合；接触估计输出低速状态（如稳定、偏松、跳动、未知）及置信度；
- 播放强、传感器削顶、双讲或未知冲击时，接触估计降级为“未知”，冻结闭环参数更新；
- 不承诺“即时”，以端到端时延、更新时间常数和置信度门限定义性能。

## 4. 样机实验矩阵

### 4.1 机械机构矩阵

| 因素 | 建议水平 | 测量 |
|---|---|---|
| 机构 | 基线镜腿；凸轮—弹簧；浮动座＋线性弹性；浮动座＋屈曲/准零刚度 | 力—位移、姿态、摩擦/异响、过载 |
| 头宽/位移 | 按目标用户 5/25/50/75/95 百分位转换；另加装配偏差 | `F_target`、`e_F`、接触位置 |
| 耳部几何/硬度 | 至少 3 种曲率×3 种等效硬度的假耳 | 法向/切向力、滑移、声学传递函数 |
| 温度/湿度 | 建议工程筛选 -10/25/45°C；常湿与高湿 | 力平台、迟滞、零位、材料松弛；这些温度为试验建议而非标准限值 |
| 保持时间 | 0、30 min、2 h、8 h | 应力松弛、接触位移漂移 |
| 循环 | 0、1k、10k、50k 次起步，并按产品寿命模型扩展 | 平台漂移、裂纹、间隙、异响、残余变形 |
| 过载 | 超出工作行程的受控位移/开合角 | 止挡峰值力、永久变形、失效模式 |

机械 Go 条件应由团队填值，但至少包括：规定区间内 `e_F`、最大滞回、8 h 力保持率、循环后漂移、最大过载力、横向跳变为零，以及无尖锐/夹伤失效。

### 4.2 声学与感知矩阵

仪器：力传感器（接触真值）、VPU-A/B、近耳 Air Mic、耳道/HATS 麦、规定旁听点参考麦、已知 CC/AC 驱动、可选激光测振或参考加速度计；全部同步采集。

| 变量组 | 水平 |
|---|---|
| 接触 | 无接触、轻/中/重接触（由实测 N 定义）；稳定、慢滑、周期跳动、随机冲击 |
| 驱动 | CC 单独、AC 单独、两者同时；扫频、多音、语音、粉红噪声；不同电平 |
| 外界 | 安静、扩散噪声、定向说话声、风噪、走路/咀嚼/触碰镜腿 |
| 使用状态 | 静默播放、本人说话无播放、播放＋本人说话、他人说话、通话双讲 |
| 个体/假耳 | 多种耳廓硬度/几何和头宽；人体阶段须另行伦理/安全设计 |
| 算法 | Air Mic only；VPU only；Air＋VPU；Air＋双 VPU；线性自适应；线性＋NN 门控 |

### 4.3 关键指标

1. **接触力回归**：MAE、RMSE、95% 误差、跨人/跨假耳误差、置信区间。
2. **状态识别**：稳定/偏松/跳动/未知的宏平均 F1、AUROC、误报率、检测时延。
3. **路径辨识**：传递函数幅相误差、频域相干度、时变跟踪误差。
4. **双 VPU 可分性**：2×2 混合矩阵奇异值比/条件数、跨姿态稳定性；条件数过大即不宣称可分离。
5. **声学效果**：耳道 SPL/频响误差、规定旁听方位的漏音 SPL、语音可懂度/质量（按产品场景选 STI、ESTOI、PESQ/POLQA 等；须遵守其适用范围和许可）。
6. **非线性**：THD、IMD、谐波/互调能量、跳动瞬态峰值、削顶率和残差谱。
7. **闭环安全**：最大增益步长、振荡/啸叫次数、错误更新率、降级触发准确率、端到端延迟、功耗。

## 5. 必须写进设计与专利材料的失败条件

- 接触力超出训练/标定范围，耳部几何或垫材变化导致模型外推；
- VPU 被播放振动或机械冲击削顶，无法同时保证通话和状态估计；
- Air Mic 环境噪声高于泄漏信号，或单点泄漏与空间总泄漏不相关；
- 两枚 VPU 的传递向量过于相似，混合矩阵病态，双传感器仍不可稳定分离；
- 接触跳动期间错误更新自适应滤波器，引起增益发散、啸叫或音质突变；
- 凸轮摩擦、铰链间隙、柔顺件横向屈曲、泡棉松弛或 NiTi 温漂使力平台失效；
- 佩戴者说话、咀嚼、走路和触碰镜架被误判为 CC 接触异常；
- 机械耦合器/HATS 与真人差异过大，台架结果不能外推到人体。

## 6. 面向交底书的推荐表述

### 建议保留

- “在规定相对位移范围内，使接触力相对于目标值的偏差不超过阈值”；
- “基于已知致动参考与多传感观测估计至少一个传递路径参数、接触状态或非线性残差”；
- “当置信度低于阈值或检测到削顶/跳动时，限制、冻结或回退参数更新”；
- “第一振动传感器位于致动器/浮动座，第二振动传感器位于镜腿，其位置根据路径可观测性或混合矩阵条件数选择”；
- “通话语音增强与接触状态估计共享振动传感器，但采用参考消除、时频资源分配或状态门控”。

### 建议删除或收窄

- “VPU 只拾取纯固体振动” → “VPU 对接触振动更敏感、对空气声相对不敏感，具体交叉灵敏度经标定获得”。
- “完全分离 CC 与 AC” → “降低路径混叠或在满足可辨识条件时估计各路径贡献”。
- “保持恒力” → “在规定工况内限制力波动”。
- “瞬时/即时调整” → “在规定检测延迟和更新周期内调整，并受稳定性与置信门控约束”。
- “简单负反馈不能用” → “固定线性反馈在强时变/非线性接触下可能不足；可采用自适应线性模型与非线性状态估计组合”。

## 7. 推荐下一步（按优先级）

1. 先做无人体的机电声同步台架：两种机构×假耳/头宽矩阵，获取 `F—x—H(f)—漏音` 数据。
2. 先验证单 VPU-A＋Air Mic＋两个已知驱动参考；只有当镜架辐射残差仍高且双 VPU 混合矩阵条件数明显改善时，再增加 VPU-B。
3. 先用可解释基线：RLS/NLMS＋特征回归/分类；NN 仅在基线无法覆盖的非线性残差上增加，并采用留一受试者/留一假耳验证。
4. 依据数据冻结 `F_target`、工作行程、力波动、频带、检测时延和置信度门槛，再进入独立权利要求撰写。
5. 人体试验前单独完成舒适、皮肤接触、声暴露和伦理/安全评估；台架声学有效不等同于人体长期安全。

## 8. 标准适用边界

- [IEC 60318-6:2007](https://webstore.iec.ch/en/publication/1447) 可用于借鉴骨振器机械耦合器 125 Hz–8 kHz 的可重复输出力测量，但 IEC 明确指出耦合器上的力通常不等于真人乳突，且目标产品为耳软骨接触，必须另建代表性假耳/人体关联。
- [IEC 60118-9:2019](https://webstore.iec.ch/en/publication/59653) 给出骨导助听器性能测量方法，可借鉴测试报告结构，但不自动适用于消费级 CC 眼镜。
- [ISO 389-3:2016](https://www.iso.org/standard/59759.html) 是骨导听力计参考零级/耦合条件标准，不是本产品音质或舒适度限值。
- [ASTM F2516-22](https://store.astm.org/f2516-22.html) 可用于 NiTi 材料平台强度和残余伸长检验，不替代整机镜腿疲劳与环境试验。
- 泡棉试验需按具体材料选择标准；ASTM D3574 针对柔性聚氨酯泡棉，不能直接宣称覆盖所有硅凝胶或硅泡棉。
