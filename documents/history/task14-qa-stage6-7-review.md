# task #14 独立 QA 复核意见

## 结论

**GO-WITH-CHANGES（修改后方可冻结为代理人评审稿）**。

本稿可以作为 P1 候选方案的阶段 6–7 技术交底底稿，但不能据此宣称可专利、可授权或完成 FTO。宽泛的“骨导 + 气导 + 麦克风反馈 + 气导抵消骨导空气辐射”继续 **BLOCK**；P4 结构案继续 **BLOCK**。本次发现 3 项必须修订、4 项建议修订。

## 必须修订

### M1｜独立项仍需把候选差异写成可核验的组合关系

5.2.1 的步骤 1–6 已包含双区域、显式约束、三类输出和置信度回退，方向正确；但“第一/第二观测集合”“近耳或外泄区域”“显式约束”仍偏功能性，且第 4–5 步可能被读成气导修正骨导泄漏的宽泛闭环。

建议在独立方法项候选中明确：

1. 第一观测集合对应佩戴者近耳区域，第二观测集合对应与近耳区域空间分离的至少一个外部泄漏区域；
2. 分别生成近耳质量指标和外部泄漏指标，并明确两者不是同一误差量的不同名称；
3. 在同一求解周期内，以近耳质量下限、外泄上限及稳定/安全约束联合求解骨导内容、气导内容和气导外泄修正三类控制量；
4. 置信度需与被更新模型对应，任一必要置信度不足时冻结相应更新并执行预定义回退；
5. 保留一句显式排除：不得将本候选项概括为“检测漏音后驱动气导抵消骨导漏音”。

该修订只能增强候选差异表达，**不能据此推定避开 US10699691B1**。正式 claim chart、审查历史和目标法域状态刷新仍是申请前门禁。

### M2｜公式（3）–（4）的符号/相位逻辑需写清

当前 `A_repair = H_r E_ext`、`A_drive = A_content + A_repair` 未明确 `E_ext` 是目标减观测还是观测减目标，也未说明抵消相位由 `H_r` 的复数相位实现。仅以“相加”表达容易造成正反馈或同相增强歧义。

建议补充：

- 定义残差极性，例如 `E_ext = Y_ext,target − Ŷ_ext`；
- 说明 `H_r` 包含次级路径补偿、幅度及相位/符号，其目标是在稳定性和驱动约束下使预测外泄残差下降；
- 若采用相反残差定义，则在公式（3）前显式加负号；两种写法只保留一种；
- 说明因果裕量不足、次级路径失配或饱和时禁止更新 `H_r` 并回退。

### M3｜置信度不可只用一个未分解的 `C_cpl`

正文称其为“耦合与观测模型置信度”，但单一标量可能让高耦合置信度掩盖低外泄观测置信度。建议至少定义 `C_bone` 与 `C_leak`（多麦时再含 `C_map`），并规定对应门控，例如采用分别阈值或 `min()` 聚合；更新 `H_b/H_a/H_r` 时注明各自依赖的置信度。公式、参数表、流程和独立项应保持一致。

## 建议修订

### S1｜目标函数的文字与公式不一致

文中称“具体定义见公式（5）”，但公式（5）只引用 `D_q` 与 `Φ_i`，未给出平方短缺/超限的明确表达。建议补充例如 `D_q=[max(0,Q_min−Q_near)]²`、`Φ_i=[max(0,L_ext,i−L_max,i)]²`，并说明所有项归一化后才加权。

### S2｜证据与工程推断边界应在本稿内可见

噪声场景中“骨导高频/辅音补偿”可作为研究提示；“由气导承担对应频带补偿并提升本系统效果”仍是工程假设。建议在 6.4 和 6.6 分别标注“文献直接证据 / 工程推断 / 待四模式样机验证”，避免代理人或研发把研究结果直接写成确定技术效果。

### S3｜P4 门禁表达应更直接

5.2.4 已排除镜腿隔振、声腔/声口结构等内容，但建议增加一句：**P4 结构案未获放行，缺少剖面图、材料、关键尺寸/公差和对照数据，不得从本稿拆分独立结构权利要求。**

### S4｜Word/PDF 图表版式

已逐页检查 PM 提供的冻结 PDF 预览（11 页）：正文、表格和公式未发现裁切、重叠或页码异常；但第 4 页系统框图与第 5 页流程图字号过小，打印或普通缩放下不可读，且第 4 页连线交叉较多。必须将两图分别放大至接近整页宽度，优先改为横向页或拆成两图，保证节点文字不小于正文常用可读字号，并减少交叉线。

本机缺少 LibreOffice，无法完成独立 DOCX→PNG 重渲染；因此上述版式结论仅基于所附冻结 PDF 预览，**不等同于 DOCX 自主渲染通过**。修订后应由可用 Word/LibreOffice 环境重新导出 PDF 并逐页复核。
