## 1. 已确认的关键事实

1. **US10699691B1 阻断成立。** 独立权利要求 1 明确包含眼镜式框架、骨导扬声器、气导扬声器、两支气导麦克风、参考/误差信号、生成抵消音并由气导扬声器对骨导空气辐射形成破坏性干涉；独立权利要求 3/16 还覆盖更宽的一麦/方法框架。代表链接：<https://patents.google.com/patent/US10699691B1/en>。
2. US10699691B1 的公开信息显示优先权日 2017-06-29、Amazon Technologies、美国授权文本；Google Patents 显示 Active，但该状态声明本身带有“非法律结论”提示，正式申请/FTO 前必须通过 USPTO Patent Center、Assignment 与目标法域代理人刷新。
3. 论文/标准 dossier 的核心方向基本合理：单气导不等于空气声阵列；多麦主要增强观测/拾音，不自动产生输出波束形成；完整“1 气导 + 1 骨导 + 双/多麦”组合尚需样机对照，不能承诺效果。

## 2. 必改 issue list

### P0｜阻断项：宽泛主案

- **问题**：任何仅以“眼镜 + 骨导 + 气导 + 麦克风反馈 + 气导反相抵消骨导漏音”为核心的独立项，均与 US10699691B1 高度重叠。
- **处理**：从候选主案中删除；不得写成“已规避”“具新颖性”或“可授权”。由代理人针对 US10699691B1 的权利要求 1、3、16、22 制作逐项 claim chart，并核验审查历史、权属与有效性。

### P1｜双区域、多目标闭环：有条件保留

- **问题**：当前“近耳可懂度 + 外部泄漏 + 耦合置信度 + 联合分配”是差异化假设，尚无检索完备性或样机证据支撑；“气导内容分量 + 抵消残差同时输出”也未冻结峰值、失真、稳定裕量和因果性。
- **修改门槛**：补充一页可实施信号框图，定义两类观测、三类输出分量、目标函数/约束、更新周期、发散检测和安全回退；至少与纯骨导、纯气导、固定混合、简单切换四基线比较。完成前只能标记“候选差异化方向”，不能标记“主案可保护”。

### P2｜多麦外泄声场重构：修改

- **问题**：单个气导辐射源不能据多麦输入推导出传统输出波束形成；“虚拟监听点/多个方向泄漏约束”缺少阵列几何、路径模型、可观测性与稳定性说明。
- **修改门槛**：统一改称“多麦空间观测/外泄场估计”；若继续主张虚拟误差点，需给出麦克风位置、校准方法、DOA/空间协方差、因果裕量和失配回退。传统输出波束形成仅能作为未来增加第二气导单元后的另案。

### P3｜正常内容驱动的佩戴/骨耦合识别：修改

- **问题**：Meta US10658995B1 已覆盖气/骨换能器多频校准；当前“无需专用测试音、正常内容在线辨识 + 置信度门控”尚缺可观测量和辨识算法。
- **修改门槛**：冻结输入信号（近耳麦、外泄麦、IMU、接触力或电学响应至少一种）、持续激励条件、置信度定义、重校准触发阈值和低置信度回退。否则说明书可能支持不足。

### P4｜机械—声学结构案：暂时阻断

- **问题**：现有材料仅列接触区、隔振、声腔/声口与测点，没有结构图、尺寸范围、耦合关系或对比效果；同时已有双换能器结构及单单元反相声口先例。
- **解除条件**：提交镜腿剖面/爆炸图、材料与尺寸范围、振动传递路径、气导声路、测点位置，以及至少一组隔振/漏音/耳旁输出对比数据。

### P5｜隐私等级驱动约束：修改

- **问题**：仅按“验证码/通知/媒体”分类并改变策略，容易退化为业务规则；隐私分类误判与本地数据处理边界未定义。
- **修改门槛**：把内容等级绑定到可测的泄漏阈值、声学控制量和安全回退；说明分类输入、误判处理、本地/云端边界及最小数据保留。作为从属项优先，不建议当前独立成案。

## 3. 证据 dossier 的具体修订

1. **E3 表述需收窄。** 该研究确证 21 名参与者、位置差异、机械阻抗及约 2 N 前耳静压力条件；但并未作为受控自变量系统比较多个接触压力。因此将“接触位置、静压力影响传递”改为“位置和界面机械阻抗影响传递；压力变化的因果效应需另证”。论文：<https://doi.org/10.1177/23312165231168741>。
2. **E1 只能支撑骨导信号高频/辅音补偿改善，不直接证明应由气导通道补偿。** 将“气导承担 2–4 kHz 清晰度补偿”标为工程推断并要求本项目对照。来源：<https://www.isca-archive.org/interspeech_2022/toya22_interspeech.html>。
3. **E6 的 7.6 dB 仅限特定侧开孔结构、假人头及 1–7 kHz 归一化漏音条件。** 不得外推为眼镜整机或骨气协同效果。来源：<https://doi.org/10.1109/ACCESS.2025.3648340>。
4. **E9 为 2026 预印本、8 麦、100–1000 Hz、目标为入耳环境 ANC。** 9.6/11.2 dB 只能作前沿可行性线索，不得用于双麦或向外漏音性能承诺。来源：<https://arxiv.org/abs/2604.05519>。
5. 标准必须按用途分栏：IEC 60268-16/STI 与 ASTM E1130 只能作为改编评价方法；ISO 389-3/8253-1 是听力学校准思想；ITU-T H.870 是安全聆听/声剂量边界。未完成适用性评估前不得写“符合”或“认证”。
